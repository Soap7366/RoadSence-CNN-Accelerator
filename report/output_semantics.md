# 转向与性能说明

## 转向输出

当前模型dual_task_baseline2_int8_qat@619308c77fd9。训练源码FPGA_CNN-main/dual_task_lite/dual_dataset.py直接读取Udacity CH2_002 manifest中的angle为标签，没有额外归一化；dual_task_int8/run_quantization.py按弧度评估并乘180/pi换算度。

因此：steering_deg = degrees(steering_int32 × 0.000048765890998470586)。不能套用原DroNet归一化输出乘90度的控制映射。用户确认正值左转、负值右转、近零直行；UI只在绘制指针时采用左正右负，不修改模型原值。超过仪表范围的显示会限幅，日志保留原始值。

碰撞与转向采用不同任务标签。风险高不必然有大转向输出，也不能把转向头当作已训练完成的障碍绕行策略。现存视频记录第208帧风险0.99138566，转向0.06963769rad=3.98995度，与换算一致。

## 当前性能表

| 项目 | 数据来源及口径 |
|---|---|
| 板端初始化 | ready.startup_ns，板端进程启动到ready；不包含SSH连接 |
| 数据传输/每张 | timing.body_read_ns均值；JPEG总字节/正文读取总时间得到十进制MB/s。受SSH缓冲影响，不是物理网络带宽或独立单向网络延迟 |
| PS预处理/每张 | timing.preprocess_ns均值，现有板端图像准备全过程 |
| PL 计算耗时（含检测开销） | native.start_wait_ns逐图均值，PS侧真实测量，含启动前状态检查、启动写入、等待完成与检测；排除输入写入、完整回读和最终输出读取 |

PL值待处理完成后显示，缺失/非法计时显示不可用。以前的1.30232ms是65116周期/50MHz的RTL参考值，当前界面已不使用固定参考值。没有修改PL、计数器、bit/HWH或native库。不能把PS侧计时标为不含PS的纯PL周期实测。

当前推理采用单帧在途，性能不能直接套用原测量客户端窗口2的18.93图/秒。处理前视频扫描、JPEG编码、日志落盘和UI绘制也不属于PL计算时间。
